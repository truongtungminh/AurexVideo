# Asset pack FastScene

- `human-presenter/`: các pose của nhân vật trình bày mặc định.
- `audience.png`: lớp khán giả cho template một cảnh.
- `channel-avatar.png`: biểu tượng FastScene dùng trong giao diện.

Background runtime là sân khấu trắng tối giản dựng bằng CSS. Nhân vật tùy chỉnh được lưu trong thư mục dữ liệu người dùng của ứng dụng desktop.
